F-Droid Repository

Blind Community Apps by Adrian Van der Berg

Add this repo to F-Droid:

https://avanderberg48-collab.github.io/fdroid-repo/repo
  1. Open F-Droid app
  2. Go to Settings > Repositories
  3. Tap + to add new repository
  4. Paste the URL above
  5. Tap OK to add

8 apps available: AccessiChat, Ask Mandy, WaveCast, CloudPhone, Connecti, Ignite Dating, Mandy Agent Offline, Adrian Browser
